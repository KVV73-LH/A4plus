# Копицентр А4 ПЛЮС — GitHub Pages

Подготовленная статическая версия сайта. Страницы, калькулятор, стили, Webflow JavaScript и изображения в папке `jpg` с короткими именами находятся в репозитории и используют относительные пути, поэтому проект работает в подпапке GitHub Pages.

## Опубликовать сайт

1. Создайте GitHub-репозиторий.
2. Загрузите **всё содержимое этой папки** в корень репозитория; `index.html` должен лежать прямо в корне.
3. В GitHub откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
5. Дождитесь публикации и откройте адрес, который появится в настройках Pages.

Сайт работает как статическая сборка: установка Node.js не требуется.
